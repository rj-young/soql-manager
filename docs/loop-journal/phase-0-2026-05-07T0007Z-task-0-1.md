## Anything surprising

A lot. In rough order of how much it disrupts the PRD as written:

1. **`yarn install` is broken in this sandbox.** `apps/studio/package.json` pinned `xlsx@0.20.3` to a `cdn.sheetjs.com` tarball. The Claude Code web egress proxy blocks that host (`x-deny-reason: host_not_allowed`). Confirmed npm has no `xlsx@0.20.3`, GitHub has no `v0.20.3` tag, and `cdn.jsdelivr.net` is also proxy-blocked. User authorized a YAGNI amendment: stub `xlsx` via `.yarn/packages/xlsx-stub/`, slated for proper removal in Task 1.3. Committed as `fee40491`.
2. **Postinstall fetches Electron headers from a proxy-blocked host.** `electron-rebuild` pulls `https://www.electronjs.org/headers/v39.8.5/node-v39.8.5-headers.tar.gz`. That asset is **not** mirrored on `github.com/electron/electron/releases`. Worked around with `--ignore-scripts`; this defers `yarn test:unit` and `yarn bks:build` to local (PRD §7 amendment v0.3).
3. **`yarn all:lint` references nonexistent workspaces.** The script chains `yarn workspace beekeeper-studio lint && yarn workspace sqltools lint && npx eslint 'shared/**' --fix`. Neither `apps/sqltools/` nor `shared/` exists in this fork. Use `yarn workspace beekeeper-studio lint` directly.
4. **Lint coverage is zero.** ESLint v6.8.0 is end-of-life (since 2020). `apps/studio` has no eslint config file. With no config + no args + v6, eslint prints help text and exits 0. The "lint gate" in PRD/brief is theatre on this fork. Adopting a real config is out of scope for Task 0.1.
5. **`tsc --noEmit` is red on HEAD: 274 errors.** Distribution: 135 in `src/`, 69 in `tests/`, 65 in `src-commercial/`, 5 in `e2e/`. Many are in DB driver files that Phase 1 cleanse will delete (Cassandra, ClickHouse, DuckDB, Firebird, libsql, etc.) — count should drop sharply by end of Phase 1. The team ships via `ts-jest` with `isolatedModules: true`, which skips cross-module type checks; that's why the codebase ships at all.
6. **`SF_API_VERSION` could not be network-confirmed.** The proxy blocks `login.salesforce.com`, `test.salesforce.com`, and `www.salesforce.com`. Pinned `66.0` (Spring '26) by release-calendar inference; documented in `docs/api-version.md` with re-verify instructions for the first real My Domain available.
7. **Branch contract conflict.** Harness pinned us to `claude/review-prd-ralph-docs-eyWub`. The Ralph brief names `feat/soql-manager-phase-1-cleanse`. Honoring harness instruction takes precedence here; `docs/upstream-pin.md` flags this for future sessions.
